# ADR: Architecture Gates

**Status:** Accepted (2026-10-29)

## Context

AI-generated code tends to copy instead of extract, swallow errors silently and
introduce dependency cycles while the build stays green. These should stop in CI,
not in review.

Stack inventory: the app is Swift/SwiftUI (one Xcode target generated by XcodeGen),
with no linter configured. CI is a single GitHub Actions job (`.github/workflows/ci.yml`,
`macos-14`) that runs a secret scan and `./build.sh`.

## Decision

- **Duplicate threshold:** the CI job runs `npx --yes jscpd@5.4.2 BlitztextMac
  --min-tokens 70 --threshold 6` before the build. No dependency is added to the repo.
  Baseline on 2026-10-29: 11 clones, 5.70 % duplicated lines in 28 files. The threshold
  of 6 % is the ratchet: existing duplicates stay, new copies push it over and fail.
- **Silent error swallowing:** not checked. There is no linter in the repo (no SwiftLint),
  and adding one is out of scope.
- **Dependency cycles:** not checked. All sources form one Swift module without imports
  between files, and no existing tool reports cycles.

## Rule for the agent

Do not copy blocks of code; extract shared code into a function or type. If the gate
fails, remove the duplication instead of raising the threshold. Lower the threshold
when duplicates are removed. New tests carry the acceptance-criterion ID in their name.

## Consequences

The CI run downloads jscpd via npx (a few seconds). A linter-based check for
silent `catch` blocks and cycles can be added later together with SwiftLint.
